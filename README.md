## ✨ Website Features

- 📖 **Inline Notebook Viewer** — renders `.ipynb` cells (Markdown + code) directly in the browser
- ▶️ **Live Code Execution** — run C++ and Python cells via the [Piston API](https://emkc.org/api/v2/piston/execute) (no setup needed)
- ⚡ **Open in Colab / Binder** — 1-click launchers to run any notebook on Google Colab or MyBinder
- 🔍 **Search** — instant search across all phases and notebooks
- ❤️ **Favorites** — bookmark notebooks for quick access (saved in localStorage)
- ✅ **Progress Tracking** — mark notebooks as completed and track overall progress
- 🌙 **Dark / Light Mode** — neumorphic design in both themes
- 📱 **Responsive** — works on mobile, tablet, and desktop

## 🚀 How to Use

1. Visit the **Live Website** link above
2. Pick a Phase from the left sidebar
3. Click any notebook to render it inline
4. Hit **Run** on any code cell to execute it live
5. Or click **Open in Colab** to run on Google Colab
